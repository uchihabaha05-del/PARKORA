# PARKORA

A mobile 3D amusement park tycoon built with Godot 4.3 and GDScript.

## Current prototype
- Stylized procedural 3D park environment
- Free orbit camera with touch and mouse controls
- Basic construction mode (carousel, tree, path tile)
- Starter cash and construction costs
- Landscape Android layout

## Open in Godot
1. Install Godot 4.3.
2. Clone or download this repository.
3. Import the folder containing `project.godot`.
4. Run the main scene.

## Controls
- Drag: orbit camera
- Mouse wheel / pinch: zoom
- Select a construction item, then tap/click the ground to place it

The project is an early playable foundation. Android export and APK packaging are intentionally deferred.
